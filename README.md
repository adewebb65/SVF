# Space Value Foundation — one-page site

A single static page (HTML + CSS only, no JavaScript) summarising spacevaluefoundation.com.

## Files
- `index.html` — all content
- `styles.css` — all styling, animations and the star field
- `img/` — images copied from the WordPress site (converted to WebP)

## Hosting on GitHub Pages
1. Push these files to the root of a repository.
2. Settings → Pages → Deploy from branch → `main` / root.

Scroll-triggered build effects use CSS scroll-driven animations (Chrome, Edge, Opera, Safari 26+).
Other browsers show all content fully, without the scroll effects.
